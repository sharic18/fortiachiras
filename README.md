# Fortiachiras – Bizcochos del Huila

Plataforma web (Spring Boot 4 + PostgreSQL + HTML/Bootstrap/jQuery) para promocionar y gestionar
los bizcochos tradicionales del Huila: catálogo, cultura, proceso, puntos de venta, carrito por
WhatsApp y panel administrativo con JWT, Swagger, reporte PDF, i18n (ES/EN/FR) y trigger de auditoría.


## Direcciones
